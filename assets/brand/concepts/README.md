# ImageSilo logo concepts

These files preserve logo exploration rounds before a final vector identity is selected.

Important: ImageGen concept boards are raster PNG previews, not production SVG files. The exact generated PNGs are committed so the visual directions cannot be lost. After a direction is selected, it must be redrawn as deterministic, editable SVG artwork with light, dark, icon-only, favicon, and horizontal-lockup variants.

## Shared references

- WILL homepage logo: bold rounded geometry, charcoal `#17181c`, coral `#ff4249`, clean technical wordmark.
- Keeper logo: overlapping rounded image-card rhythm and confident geometric wordmark.
- References are style context only. ImageSilo concepts must remain original and must not copy either symbol.
