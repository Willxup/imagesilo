# 浏览器按需验收

项目不依赖 Playwright 或其他固定浏览器测试框架，不下载或维护专用浏览器。界面、导航、剪贴板、响应式布局等浏览器行为变更，使用现有浏览器人工或通过 computer-use 工具按需验收。外部工具由操作者选择，不作为仓库安装、构建或 CI 的前置依赖。

`make check` 保留 Go 单元/集成测试、前端 Vitest、Lint、类型检查、OpenAPI 一致性检查与生产前端构建；它不验证真实浏览器交互。构建成功、单元测试通过或截图不能替代浏览器验收。以下清单承接原桌面/手机 E2E 场景，不表示这些场景已执行或仍由 CI 自动覆盖。

## 准备

- 按 README 构建并启动本地二进制，使用独立测试数据目录和测试管理员，禁止使用生产数据或凭据。通过实际 Go 服务访问生产前端，而不只查看 Vite 页面。
- 本机 HTTP 调试仅在回环地址使用 `IMAGESILO_COOKIE_SECURE=false`；远程环境使用 HTTPS，保持安全 Cookie。
- 准备一张微型有效 WebP 图片；桌面和手机各上传一张，避免不必要的资源开销。
- 涉及迁移管理时，按[导入指南](./imports.md)在独立测试目录准备 `/i/2026/08/migration-desktop.webp` 和 `/i/2026/08/migration-mobile.webp`，仅对这些可丢弃文件启用 `IMAGESILO_MIGRATION_MUTATIONS=true`。删除验收不得指向真实迁移目录。
- 桌面至少检查 1280 × 720 与 1024 × 768；手机可使用现有浏览器的移动视口模拟（例如 393 × 851），注明是否为真机。授予必要的剪贴板权限；不能读取时实际粘贴到本地输入框核验，不记录敏感内容。

- [ ] 在 1024 × 768 下，上传链接格式菜单不越出内容区；恢复宽屏后布局正常。
- [ ] 图片管理显示真实缩略图（`/api/v1/images/.../thumbnail/`）；选中图片后的批量复制主按钮与下拉按钮等高，格式菜单在工具栏上方且无遮挡。
- [ ] 打开详情进入 `/admin/images/{id}`，图片名正确，Markdown 复制有效。
- [ ] 迁移管理在慢速网络下显示扫描中状态；文件缩略图可见，刷新/应用筛选按钮样式一致（14px），键盘 Enter 刷新有成功反馈。
- [ ] 迁移永久删除开关状态明确，复制链接指向原路径；确认删除测试文件后卡片消失，该路径返回 404。
- [ ] 路径映射上传另一份测试图片并创建 `/legacy/browser-check.webp`，旧 URL 返回 200 与 `image/webp`。
- [ ] 创建带 `images:upload`、`images:read_private` Scope 的测试 Token；通过 API 上传私密图片返回 201，匿名读取返回 401，携带 Token 读取返回 200。可使用[API Token 指南](./api-token-usage.md)中的请求方式，不把 Token 写入 URL 或验收记录。

- [ ] 全新数据目录下，同格式压缩和 JPEG/PNG 转 WebP 默认关闭；系统页数据库与图片/别名索引数量一致。
- [ ] 切换深色与 English 后，刷新仍保持主题和语言，导航文字正确。

- [ ] 通过菜单进入图片管理，图片卡片可见；切换私密/公开后状态正确，直链复制有效。

## 记录与清理

每次根据变更选择相关场景，涉及跨页面流程时执行完整桌面和手机闭环。记录：

| 项目 | 内容 |
| --- | --- |
| 版本 | 提交或工作区、构建方式 |
| 环境 | 浏览器名称/版本、操作系统、视口、真机或模拟 |
| 场景 | 执行的清单项、输入与预期结果（不含秘密） |
| 结果 | 实际观察、通过/失败/未验证；未执行或受阻的原因 |
| 证据 | 必要的截图、HTTP 状态、控制台/网络错误；遮盖 Cookie、Token 与私密内容 |

无法取得浏览器证据时明确写“未执行”或“未验证”，不得用 CI 通过替代。验收后停止测试服务、吊销测试 Token，并仅清理本次创建的测试数据和图片，保留需要的脱敏验收记录。
