# 阶段 4 交付索引基线

测量日期：2026-07-29  
固定模型：临时 SQLite 中保存一个图片目标，分别挂载 10,000 与 100,000 条规范化历史路径；测量完整 `delivery.Build` 数据库加载，再执行 1,000,000 次标准路径命中、别名命中和别名未命中。

测量程序先在单事务中准备数据，随后在完整索引加载前后执行 Go GC 并读取 `runtime.MemStats.HeapAlloc`。内存增量包含查询扫描后保留的索引 map、规范化路径字符串、图片 ID 值和一个交付目标；不包含 SQLite 原生内存、图片文件或 HTTP 缓冲。构建耗时从读取图片表开始，覆盖文件存在性校验、读取全部别名、严格路径校验和生成完整新 map；查找期间不访问 SQLite。
