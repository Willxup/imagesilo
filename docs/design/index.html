DESIGN STUDY / 01

先确定体验，再进入开发。

这是一份交互设计研究，不连接实际数据。可以切换左侧页面、选择图片、打开详情、展开筛选、体验模拟上传，以及比较三种整体构图。

A · 工作室

常用功能始终可见。强调稳定的操作路径与安静的画布，适合每天使用。

B · 展廊

顶部导航让出横向空间。更像个人作品库，但管理入口密集时需要进一步收纳。

C · 暗房

低亮度界面突出影像。适合深色模式；表单较多的页面需要额外保证层次。
