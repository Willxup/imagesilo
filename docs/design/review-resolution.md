## 未照原方案实施的部分

- **全量 CSS 放入 components 层**：采纳“明确归属、消除重复、基础规则可覆盖”的目标，先对通用按钮与全局 reset 分层。页面布局仍保留优先级，因为现有 JSX 的 object-cover、aspect-ratio、宽度等工具类包含旧布局默认值，整体移动层级会把已确认的不裁剪和移动尺寸规则反转。没有把这一建议当作误报，但不通过一次全量层级替换制造视觉回归。
- **删除整段旧移动样式**：报告的“100% 死代码”不准确，紧凑列表确实使用其中部分规则；删除真正被覆盖的网格声明，其余明确归入列表作用域。
- **限制长图高度**：不采用强制 70vh/固定最大高度；用户要求手机上完整、看得清图片，保留原比例，避免缩成难以辨认的长条预览。
- **反向 View Transition 缺少配对**：当前安装的 React Router `useViewTransitionState` 同时匹配 currentLocation 和 nextLocation，不需要重复维护过渡图片 ID。
- **迁移卡片始终呈现可点击**：原有 migration-tile 已设置 cursor: default。本轮进一步把悬停抬升限定到真实图片链接，迁移卡片不再应用该反馈。
- **Modal originalFocus 永久泄漏**：现有代码在最后一个弹窗卸载后已经置空，无需增加路由级全局重置。
- **matchMedia 是生产崩溃**：支持的现代浏览器具有该 API；缺少的是 JSDOM 测试替身，已在实际新增的导航单测中提供，不更改正常浏览器行为。
- **性能用例没有任何 expect**：原代码有导航可见性断言；但其帧率数据确实只是诊断，本轮按建议移出常规用例。
