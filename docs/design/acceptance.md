# UI 重构验收记录

本文记录 UI 重构各阶段的历史验收与当时使用的 E2E 工具，不代表当前自动化覆盖。Playwright 已移除；当前验证方式见[浏览器验收清单](../browser-acceptance.md)。

此表区分「设计已经明确」与「生产实现已经验证」。原型通过不代表产品通过；只有当前实现的输出、测试或运行观察可以填写通过。

## 已建立的检查基础

- 独立工作树：`worktree/prism-ui`，基于 `origin/main` 的 `0f96da6`。
- 第二轮设计依据：`decisions.md`；可交互工作区/认证原型：`index.html`、`auth.html`。
- 原有组件测试覆盖：上传拖放/空 MIME/结构化失败/成功批量复制；图库筛选/高级日期/偏好/批量复制；详情历史路径；迁移扫描/只读/允许删除/刷新/偏好；映射创建/解析/分页/错误；设置草稿保留；系统巡检/缺失文件；弹窗焦点与 inert。
- 原有桌面 E2E：登录、上传、所有复制格式相关流程、图库/私密上传、详情删除、迁移刷新/删除、映射、令牌、设置、系统、主题/语言。
- 原有手机 E2E：上传、可见性、复制、批量菜单、迁移路径。
- 新增 `web/e2e/redesign.desktop.spec.ts`：375/768/1024/1440px 的全部后台路由；手机抽屉焦点循环/Escape/焦点返回；全局搜索快捷键；减少动态效果。
- 隔离实图环境在 `127.0.0.1:18767`，使用临时数据目录，含 6 张公共来源样例图片、公开/私密状态、迁移文件与历史映射。该环境仅用于验收，不能当成用户的实际图库。

## 设计阶段已经得到的证据

- 原型在 375px 的批量栏/格式菜单位于视口内；切换 BBCode 后菜单关闭，焦点返回格式触发器。
- 原型的图库/详情窄屏检查未发现横向溢出。
- 对比度：浅色次要文字 `#5e6e75` 在 `#f2f4f4` 上为 4.80:1，在 `#f7f9f9` 上为 5.01:1；成功色 `#07795f` 在白色上为 5.37:1。
- 生产代码早期审查发现手机焦点循环可能计入隐藏折叠按钮，已要求开发过滤不可见元素并取消背景按钮 Tab 焦点。最终仍需 E2E 验证。

## 验收结果

最终验收已完成。下文保留中间版本的问题和修复依据，最终结果见文末。

### 第一轮实现审查

已将第一份成功构建的 `web/dist` 嵌入 worktree 二进制，在 18767 的临时数据库中查看上传、图库、详情、深色和 375px 英文详情。

- 上传舞台/侧选项、无外框图库、大图/检查面板已出现，和新设计的主要构图一致。
- 真实图片详情仍显示哈希、处理摘要、历史路径、WebP 转换与删除。
- 375px 英文详情实测 `innerWidth=375`，document/body scrollWidth 均为 356，没有横向溢出；复制位于长元数据之前。
- 发现主要按钮背景丢失：主按钮 computed background 为透明、文字白色。原因是 Button 仍引用已删除的渐变变量。开发已报告改为语义实色，待下一份构建复核。
- 要求统一「图片库」导航与页面标题；降低图库重复操作按钮的视觉权重；详情复制使用主操作样式；中文详情 kicker 本地化。
- 手机抽屉首次打开时观察到焦点停在 BODY，Escape 能返回触发器。已要求聚焦延后至可见帧，Tab 对外部焦点提供兜底，并加入初始焦点 E2E 断言。
- 语言菜单选择后焦点停在 BODY；键盘 ArrowUp 从触发器出发计算会跳到倒数第二项。已交给开发修正并补回归覆盖。
- 源码审查发现模块全局单值滚动恢复可能用于错误的历史项，也可能在 StrictMode RAF 取消后丢失。开发已改为 location.key 匹配和执行后消费，待真实导航 E2E 验证。

新增导航回归会阻塞详情 API 响应，确认预览图不等待完整元数据；再验证详情从顶部打开、返回同一筛选 URL 与原滚动位置。

### 第二轮实现审查

- 已查看真实浅色/深色图库、上传、登录、详情和全部管理页。工作室构图、Logo 衍生图形、侧边栏、简化图库、分区设置和双主题符合第二轮设计。
- 主按钮背景和文字已恢复语义配色；「图片库」命名统一；语言菜单选择后实际焦点返回语言触发器。
- 登录在 375px 深色下保持完整表单与页脚；桌面使用品牌叙事与表单左右分区。较矮桌面视口仍由 E2E 检查约束。
- 发现页面入场动画最终保留 transform，使手机批量工具栏的 fixed 定位相对页面而非视口，实测顶部位于 1321px（视口高 812px）。要求结束动画后移除 transform，并补批量栏视口位置与抽屉遮挡回归。
- 移除图库操作行的整体半透明处理，避免次要文字与菜单对比度下降；已有次要色和无边框样式用于降低视觉权重。
- 要求详情可见性按钮明确写出将执行的动作，避免用下箭头暗示不存在的菜单；管理页眉与 Token 权限解释全部本地化。
- 第一轮完整检查中 Go vet/test、前端 lint/typecheck 与 35 个单测通过。E2E 暴露矮屏登录高度、窄屏映射文件选择器宽度、抽屉初始焦点和旧标题选择器问题；均需修复后重新通过完整门槛。
- 详情延迟响应预览与返回筛选列表滚动位置的新增 E2E 已通过。
- 额外用全新临时实例查看初始化页，桌面双栏与 375px 单栏的全部原有字段、默认策略和提交入口均保留；375px 的 document/body 宽度为 356px，无横向溢出。此次仅观察布局，没有创建账号或提交初始化表单；临时实例已停止。

### 用户反馈后的侧栏与动效续修

- 移除左下三色装饰，只保留侧栏最底部的收起/展开按钮；标签保留 DOM 并始终单行，折叠时不挤压导航行。加入底部位置、连续折叠展开、行高与滚动位置回归。
- 普通页面只保留一次 180ms 淡入；移除标题和卡片叠加入场、逐张错峰等待。历史返回不重新播放入场，并在布局阶段恢复滚动，避免过渡先捕获错误位置。
- 图片共享过渡只注册正在打开/返回的图片，时长 300ms；详情加载占位与完成状态共用同一几何布局。延迟 API 的 E2E 验证图片舞台尺寸前后一致。
- 菜单和弹窗改为可反向续接的 CSS transition，取消弹窗内容缩放与背景模糊；滚动条留位避免打开弹窗时背景横移。修复弹窗刚出现就按 Escape 的事件注册时机问题。
- 用户指向、聚焦导航或图片时预加载对应页面代码，保持 API 数据请求边界不变；减少动态效果时取消退出卸载等待。
- 最终 `make check e2e` 退出码 0：35 个组件测试、11 个浏览器测试，以及 Go、lint、typecheck 全部通过；实际预览复核了侧栏展开/收起、图库/详情和返回。
- 本机 Chromium 在侧栏连续折叠展开期间采样 55 个帧间隔，p95 与最大值均约 16.8ms。该短时诊断用于发现明显停顿，不是跨设备帧率保证。原始数据在 `web/test-results/motion.desktop-sidebar-foo-81266-les-settle-without-wrapping-desktop-chromium/frame-spacing.json`。
