01 / 入口图库总览

搜索、筛选、排序、批量操作。首页先给全貌，空图库直接引导上传。

02 / 查看模式光桌

从任意图片进入；胶片带沿用当前筛选结果。返回保留滚动与选中。

03 / 全局动作上传面板

在图库、光桌和管理区都可唤起。收起不中断队列，完成后可复制或查看。

04 / 管理区域数据与系统

迁移文件、路径映射、API Token、设置、系统状态都有明确入口。

整体关系：登录 / 首次设置 → 图库首页 ⇄ 光桌；上传随时可用；管理集中承载数据与系统功能。主题、语言、账户在全局顶栏。
